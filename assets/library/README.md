# Practice Perfect Website Image Library

This directory is the permanent single source of truth for approved website imagery.

## Quality standard
Every production image must be sharp, high resolution, professionally composed, correctly cropped for its placement, and optimized without visible compression damage.

## Asset workflow
1. Save an approved high-resolution source under `assets/library/masters/`.
2. Create web derivatives from that master.
3. Store derivatives in the appropriate purpose folder.
4. Reference only `/assets/library/...` paths in production HTML/CSS.
5. Keep the master permanently available for future resizing or re-export.

## Do not
- Use temporary generated-image URLs in production.
- Use low-resolution placeholders when a better source exists.
- Stretch raster assets.
- Recompress already-compressed derivatives to make new versions.
- Regenerate approved graphics merely for organizational reasons.

The approved Services page remains the visual design benchmark for the site.
