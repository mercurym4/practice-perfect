# Practice Perfect Website Image Asset Library

This directory is the single source of truth for imagery used by the Practice Perfect website.

## Structure

- `logos/` — approved brand marks and logo variants
- `heroes/` — hero and banner photography
- `services/` — service-specific graphics
- `website-design/` — website design and conversion graphics
- `seo-ppc/` — SEO and paid media graphics
- `lead-generation/` — lead-generation graphics
- `direct-mail/` — direct-mail graphics
- `icons/` — approved icons and icon sets
- `backgrounds/` — reusable backgrounds
- `general/` — reusable professional imagery
- `masters/` — high-resolution source masters when available

## Rules

1. New approved imagery must be saved here before being referenced by the website.
2. Use descriptive filenames; never use generic names such as image1 or graphic2.
3. Preserve high-resolution masters. Create web-optimized derivatives from masters; do not overwrite masters.
4. Website pages must reference library paths, not temporary URLs, chat files, or scattered root-level assets.
5. Reuse approved assets when appropriate to maintain brand consistency.
6. Any asset that is visibly blurry, stretched, pixelated, or over-compressed must be replaced from its master before use.
