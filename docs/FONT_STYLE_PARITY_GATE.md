# Actual-font style migration parity

This protected-draft Chromium gate compares 13 reviewed migration targets across the established 12 widths (320, 390, 640, 641, 650, 651, 768, 980, 981, 1440, 1700 and 2560 pixels). The phase-6 set adds the Services hero grid, first card, partner panel and process grid. The candidate must produce 156 exact computed-style/rectangle/target-PNG comparisons and 156 before/after target readiness records; every before/after PNG hash must be identical and no threshold is relaxed.

For Services, the baseline moves the exact 9,489-byte prefix of `services-reference.css` back into the former `services.html` style position and serves the original remainder of the stylesheet. Other baseline transformations restore only the already reviewed phase-2, phase-4 and phase-5 migrations. Both sides retain the same current Google Fonts request topology and unrelated candidate source.

Before every snapshot, the harness explicitly loads the reviewed normal Latin faces. Services targets require Inter only. Other targets load Inter normal weights 400/500/600/700/800 and, where requested by the page, DM Serif Display normal 400. Nonempty actual `FontFace` results must have the expected family, normal style, matching weight descriptor/range and loaded status. To prevent a live provider response from changing between the baseline and candidate, the harness performs one real approved Google fetch per exact stylesheet/font URL per run and replays those exact bytes to both sides. The retained evidence records every upstream URL, status, resource type and response-body SHA-256; failed or non-200 upstream responses remain fatal. Evidence includes before/after target PNGs, exact head, Chromium version, font-face records and network outcomes.

Only reviewed HTTPS GET Google Fonts stylesheet/font requests are admitted externally; analytics/contact-form scripts are inert. HTTP errors, failed requests, unexpected external dependencies, computed-style differences, geometry differences or pixel differences fail acceptance. The independent all-page font-readiness job remains unchanged and covers all 27 sitemap pages.

This is scoped Chromium target parity, not whole-page or historical font-topology parity, exact glyph selection for every element, complete Unicode/italic coverage, measured network performance, production headers/firewall, physical-device behavior or publication. Current-head CI and its retained evidence must pass before acceptance.
